# Photoshop Add Solid Color Border

A Photoshop script that adds a solid-color border (black, white or a custom color) around a photo, sized for the print size you plan to use.

In one dialog, you enter the final photo size, the border width (in inches or centimeters, typed in or picked from a configurable list of presets) and the border color. The script works out how many pixels the border needs from the photo's own pixel dimensions, expands the canvas, and draws the border on a new layer at the top of the layer stack. The photo itself is not changed.

Two companion scripts are included: **Remove Border** restores the photo's original crop and can delete the border layer, and **Edit Border Presets** adds, edits and deletes the border width presets.

For a full description and installation instructions, see the [wiki](https://github.com/lendres/Photoshop-Add-Solid-Color-Border/wiki).

If you encounter a problem, create an issue at [issues](https://github.com/lendres/Photoshop-Add-Solid-Color-Border/issues).
