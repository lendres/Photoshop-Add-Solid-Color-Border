# Photoshop Add Solid Color Border

A Photoshop script that adds a solid black or white border around a photo, sized for the print size you plan to use.

In one dialog you enter the final photo size, the border width (in inches or centimeters) and the border color. The script works out how many pixels the border needs from the photo's own pixel dimensions, expands the canvas, and draws the border on a new layer at the top of the layer stack. The photo itself is not changed.

For a full description and installation instructions, see the [wiki](https://github.com/lendres/Photoshop-Add-Solid-Color-Border/wiki).
